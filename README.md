# Unit Converter

A static unit converter website with ad slots, ready to deploy on Cloudflare. No framework, no build step needed to deploy: the site is the plain HTML, CSS and JavaScript in `public/`.

Converters: length, weight, temperature, volume, area, speed, time, data, pressure and energy. Each has its own page with a live converter, a table of every unit, common conversions, a reference table and FAQs.

## Preview locally

```bash
python3 -m http.server 8000 -d public
```

Then open http://localhost:8000.

## Before going live

1. In `tools/build.py`, set `SITE["url"]` to your domain and `SITE["email"]` to your contact address, then run `python3 tools/build.py` to regenerate the pages.
2. Replace `example.com` in `public/robots.txt` with your domain.
3. After AdSense approves the site, put the line AdSense gives you into `public/ads.txt`.

## Ads

All ad settings are in `public/assets/js/ads-config.js`.

| Placement | Slot name | Size |
|---|---|---|
| Top banner | `top-banner` | 728 × 90 (320 × 100 on mobile) |
| Vertical banner, right | `rail-right` | 300 × 600, sticky (screens 1100px and wider) |
| Vertical banner, left | `rail-left` | 160 × 600, sticky (screens 1400px and wider) |
| Tiles | `tile-1` to `tile-4` | 300 × 250 (tiles 3 and 4 hidden on phones) |
| In-content banner | `in-content` | 728 × 90 (320 × 100 on mobile) |
| Bottom banner | `bottom-banner` | 728 × 90 (320 × 100 on mobile) |
| Video, bottom right | `video` | 320 × 180 floating player, closable |
| Full-screen | `interstitial` | Shown between pages, once per visit |

To turn on AdSense, set `adsenseClient` to your publisher ID and paste an ad unit ID for each slot. Set `showPlaceholders` to `false` before launch so any slot without an ad collapses instead of showing a grey box.

The video and full-screen slots are for direct-sold ads or another ad network's tags. AdSense does not allow its ads inside custom pop-ups or floating players; for AdSense, turn on **Auto ads > Vignette ads** (full-screen between pages) and **Anchor ads** in the AdSense dashboard instead.

## Editing pages

The HTML pages, `public/assets/js/units.js` and `public/sitemap.xml` are generated by `tools/build.py`, which holds the unit definitions and page text. Edit that file and run `python3 tools/build.py`. Styles (`public/assets/css/style.css`) and scripts (`public/assets/js/converter.js`, `ads.js`, `ads-config.js`) are edited directly.

## Deploy to Cloudflare

**Cloudflare Pages (Git):** connect this repository, leave the build command empty, and set the build output directory to `public`.

**Cloudflare Workers (CLI):** `npx wrangler deploy` uses `wrangler.jsonc`, which serves `public/` as static assets.
